# Working Data Entry

Use this folder for human-friendly poem entry files before they are converted to
JSONL.

Recommended flow:

1. Copy `bulleh_shah_entry_template.md`.
2. Rename it, for example `bulleh_shah_0001.md`.
3. Type or paste the original source-script text.
4. Add transliteration.
5. Add literal gloss.
6. Add literary translation.
7. Add tashreeh.
8. Add source and review notes.

Keep all files saved as UTF-8.

Only commit entries that are safe to publish. If a source is copyrighted or
uncertain, keep it outside the public repo or use a private ignored folder.
