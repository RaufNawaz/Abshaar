# Original

ہو نہیں سبھے گلڑیاں

ہو نہیں سبھے گلڑیاں، اللہ اللہ دی گل
کجھ رولا پایا عالماں، کجھ کاغذاں پایا جھل

- Language spans: Punjabi

# Transliteration

ho nahīṉ sabhe galṛiyāṉ, allāh allāh dī gal
kujh rolā pāyā ʿālmāṉ, kujh kāġẖdāṉ pāyā jhal

# Literal Translation

Talk only of God, the rest is merely chatter,
though scholar and priest have tried to confuse the matter.

_Reference translation by Taufiq Rafat, "Bulleh Shah: A Selection" (Vanguard, 1982), p.179. COPYRIGHTED — private reference only; do NOT publish or use for training._

# AI Translation

All else is idle prattle — the [only true] talk is "Allah, Allah."
Some of the confusion the scholars have raised, some clamour the paper-and-books have stirred.
