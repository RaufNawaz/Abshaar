# Transliteration

Chal Bulleh! chal oothe chaliye, jithe saare annhe
Na koi saadi zaat pachhaane, na koi saanoon manne

# Literal Translation

So that none will run before or behind
let us go to a place where all are blind.

_Reference translation by Taufiq Rafat, "Bulleh Shah: A Selection" (Vanguard, 1982), p.49. COPYRIGHTED — private reference only; do NOT publish or use for training._
