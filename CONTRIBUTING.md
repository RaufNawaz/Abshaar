# Contributing

Abshaar is meant to be a careful public archive, so contributions should be
small, sourced, and reviewable.

## Good First Contributions

- Fix a typo in documentation.
- Add a source citation.
- Add one glossary term.
- Correct one transliteration.
- Add one timeline event with a source.
- Improve one translation note.
- Improve the website once the website exists.

## Content Contribution Requirements

Every content contribution should include:

- source name;
- source URL or bibliographic reference;
- license or rights status;
- contributor name or handle;
- confidence level;
- note on uncertainty, if any.

## Translation Review Principles

- Preserve concrete imagery before explaining metaphysical meaning.
- Separate literal gloss, literary translation, and tashreeh.
- Mark alternate readings when serious ambiguity exists.
- Do not flatten poet-specific terms into generic spirituality.
- Do not treat one printed version as the only authentic version when oral or
  regional variation matters.
- Credit singers, teachers, translators, and communities where relevant.

## Pull Request Checklist

Before opening a pull request:

- confirm no private or copyrighted source files were added accidentally;
- confirm large model files were not committed;
- run any available tests or formatters;
- explain what changed and why;
- include source and license information for content changes.

## AI-Generated Contributions

AI-generated drafts are welcome only when labeled as drafts. A human reviewer
must approve translations, explanations, glossary entries, and historical claims
before they are treated as publishable.
